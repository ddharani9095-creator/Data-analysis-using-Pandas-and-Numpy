NumPy & Pandas Quick Reference

A personal cheat sheet covering core NumPy and Pandas syntax — built while working through hands-on exercises in the Entri Elevate "AI Driven Data Analytics" program.

What's Inside
NumPy Arrays — creating 1D/2D arrays, inspecting shape/dtype/size, vectorized math, slicing and indexing
Pandas Series — creation with custom indices, .loc vs .iloc, boolean filtering, modifying and dropping entries
Pandas DataFrame — creation, exploration (head, tail, dtypes, value_counts, groupby), filtering with multiple conditions, adding/removing rows and columns
Common Mistakes — a table of real syntax errors made while learning (typos, missing quotes, capitalization) and their fixes
Key Concepts — quick reminders on .loc vs .iloc, vectorization, and slicing behavior
Why This Exists

Built as a quick-lookup reference to revisit core syntax patterns without re-reading full documentation — useful for assignments, interview prep, and day-to-day data analysis work.
